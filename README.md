# Acerola Jam 0

My entry for the Acerola Game Jam 0: a small 3D game made with Godot 4.2, with a character
controller, a bedroom level, flying arrows and a custom outline shader.

## Running it

Open `project.godot` in Godot 4.2 and press Play. The `.blend` models need
[Blender](https://www.blender.org/) configured in Godot for import.
